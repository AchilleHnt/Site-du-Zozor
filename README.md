# Site du Zozor

Ce projet est une maquette de blog de voyage inspirée du template “Zozor”. Il a été réalisé en HTML et CSS afin de reproduire une page de blog personnel avec une structure classique et un rendu visuel soigné.

## Objectif du projet

L’objectif principal était de créer une page web statique qui reproduit un design de blog de voyage, avec :

- un header avec logo et navigation ;
- une bannière d’article ;
- un article principal ;
- une colonne latérale “À propos de l’auteur” ;
- un footer avec derniers tweets, photos et amis.

## Structure du projet

### Header
Le haut de page contient :

- le logo “Zozor” ;
- le sous-titre “Carnets de Voyages” ;
- un menu de navigation composé de liens simples.

### Bannière principale
La bannière met en avant un article de voyage avec le texte :

- “Retour sur mes vacances en Etats-Unis...”
- un bouton “Voir l’article”.

### Section principale
La page contient un article de blog avec un texte de démonstration, ainsi qu’une autre zone dédiée à l’auteur.

### Sidebar
La colonne latérale présente :

- une photo de l’auteur ;
- une courte biographie ;
- des icônes de réseaux sociaux.

### Footer
Le bas de page contient :

- le dernier tweet ;
- plusieurs photos ;
- une liste d’amis fictifs.

## Fichiers principaux

- `index.html` : structure HTML de toute la page ;
- `styles.css` : styles du site ;
- `images/` : ressources visuelles (logo, photos, icônes, illustrations) ;
- `polices/` : polices utilisées dans le design.

## Technologies utilisées

- HTML5
- CSS3

## Comment lancer le projet

Il suffit d’ouvrir le fichier `index.html` dans un navigateur.

Aucune installation ou dépendance n’est nécessaire car il s’agit d’un projet web statique.

## Ce que ce projet montre

Ce projet met en avant :

- la structure d’une page de blog ;
- la mise en page de contenu texte + image ;
- l’organisation visuelle d’une interface web classique ;
- l’intégration HTML/CSS d’un design inspiré d’un modèle existant.

## Description courte

C’est une maquette statique de blog de voyage, réalisée comme exercice de création visuelle et d’intégration HTML/CSS.
